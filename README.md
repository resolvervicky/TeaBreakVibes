# ☕ OruTeaDa (ChaiIdle)

**OruTeaDa** is a premium, meme-inspired idle reminder for developers. It monitors your system activity and gently reminds you to take a chai break when you've been inactive for too long.

Built with **WPF (.NET 8)**, it features a modern glassmorphism UI, smooth animations, and language-aware audio dialogues.

---

## ✨ Features

- **💎 Modern UI**: Frosted glass (glassmorphism) design with a dark, premium aesthetic.
- **🎨 Custom Animations**: Hand-drawn SVG tea cup with animated steam and glow.
- **🌍 Multi-language Dialogues**: Supports Tamil, English, and Hinglish memes.
- **🎵 Smart Audio**: Picks random clips based on your preferred language.
- **⏰ Customizable**: Set your own break threshold from 1 to 30 minutes.

---

## 🚀 Installation & Usage

1. **Download**: Grab the ZIP from the [Releases](https://github.com/resolvervicky/TeaBreakVibes/releases) page.
2. **Run**: Extract and double-click `OruTeaDa.exe`.
3. **Tray Menu**: The app lives in your system tray. Right-click the ☕ icon to open Settings or Pause the timer.
